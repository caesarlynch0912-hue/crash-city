# Crash City

Ett 2D-actionspel i webbläsaren – kör, fly från polisen, samla bilar och skins.

**Spela:** öppna `index.html` i en webbläsare. Inga installationer behövs.

## Innehåll
- Öppen stad med trafik och fotgängare
- Polis, militär och helikopter som jagar dig
- Vapen, power-ups och ramper
- Garage med 8 bilar, skins och utmaningar
- Ljud och radio
